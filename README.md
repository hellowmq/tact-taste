# Tact Taste

**有分寸的交互审美。**

[English](README.en.md) · [v0.1.0 下载](https://github.com/hellowmq/tact-taste/releases/tag/v0.1.0) · [版本记录](CHANGELOG.md) · [安装](docs/INSTALL.md) · [示例](docs/EXAMPLES.md) · [来源与许可](docs/SOURCES.md)

Tact Taste 是给 AI 编程助手使用的 **UI 与交互设计技能**。当一个界面“功能能用，但层级散、状态乱、变化生硬”时，它帮助助手从布局、排版和控件关系入手，把视觉与操作一起打磨到位。

它由「交互大师」整理而来，将原有的视觉判断、12 张动效经验卡和 15 条工程经验整理为可独立使用的 Agent Skill。你把它交给助手，再给出当前项目和改进目标；助手据此查看界面、选择方案、修改实现，并验证受影响的操作。

我们偏好这样的交互：按下就有回应，变化能看出关系，中途改主意可以接上，失败以后知道怎么办。布局先说明层级，动效表达因果，文字补足仍然不清楚的部分。

这些是有取舍的审美主张，也需要接受具体产品与真实操作的检验。Tact Taste 适合改善已有网页或原生应用；选型跟随宿主，不绑定框架，不要求引入动画库。

## 用起来有什么不同

下面是设计目标示意，实际变化需要在你的项目中验证：

| 常见现状 | Tact Taste 希望做到 |
| --- | --- |
| 每一块都加标题、边框和说明，主操作仍难找 | 用分组、间距、对齐、字号和强调关系组织阅读顺序；必要的说明保留 |
| 选中态只换颜色，切换时内容和焦点各走各的 | 视觉状态、语义、焦点和对象身份对应同一个选择 |
| 动画播放漂亮，一连点就跳回起点 | 新目标从当前画面续接，允许反向、打断和取消 |
| 一按保存就报成功，失败只弹一次提示 | 区分输入、等待与真实确认；恢复入口跟随失败对象和原意图 |

## 它会做什么

| 遇到的问题 | 优先改善 |
| --- | --- |
| 层级不清、布局松散或控件关系含糊 | 分组、留白、对齐、排版比例、色彩强调与视觉状态 |
| 点击以后不知道是否生效 | 局部输入反馈、处理中、确认与失败各有依据 |
| 快速切换时跳回起点或排队播放 | 同一对象连续变化，新目标从当前状态续接 |
| 拖动被打断以后状态残留 | 指针归属、取消、释放、失焦与销毁有明确终态 |
| 界面到处都是解释和效果 | 用布局表达层级，为每个效果找到具体作用 |
| 鼠标看起来正常，键盘或静态模式失效 | 焦点、状态语义、减少动态效果和资源清理同步处理 |

保留项目已有视觉身份与用户锁定的角色、动作和业务行为。纯角色绘制、素材生成或从零定义整个品牌，通常需要另行设计。

## 它如何参与一次改进

1. **看真实界面**：确认主要任务、阅读顺序、控件关系与已有约束，实际操作当前流程。
2. **给出有依据的取舍**：指出最值得改善的视觉或交互问题，说明用户会感到什么变化。
3. **落实到现有产品**：改布局、状态或动效，保留已锁定的风格、角色动作和业务语义。
4. **验证结果**：检查静态画面与完整操作，交付改动、实际验证和仍未确认的部分。

它的价值在于给助手一套一致、可执行的审美判断。具体实现使用项目已有的技术；它本身是随项目工作的技能文件。

## 开始使用

取得本项目文件后，在 `tact-taste` 目录执行下面的命令。需要 Python 3.9 或更新版本；安装只复制技能文件，不下载依赖、不改其他技能，也不覆盖已有目标。

```sh
python3 scripts/install.py --to "$HOME/.codex/skills/tact-taste"
```

打开新会话后，按宿主支持的方式选择技能，或明确要求助手读取安装后的 `SKILL.md`：

```text
用 $tact-taste 改善这个页面的 UI 与交互。保留品牌配色和业务逻辑，
先看层级、分组、间距、排版和控件状态，再打磨切换、保存与取消。
直接实现最有价值的改进，实际运行，并说明验证结果。
```

Claude Code 的目录与调用方法、旧 `interaction-master` 的迁移方法见[安装说明](docs/INSTALL.md)。从 [v0.1.0 Release](https://github.com/hellowmq/tact-taste/releases/tag/v0.1.0) 下载 `tact-taste-v0.1.0.zip`，解压到空目录后即可执行上述安装命令；同页提供 SHA-256 校验文件。也可以从[公开仓库](https://github.com/hellowmq/tact-taste)取得源码。

## 看得到、操作得到的示例

直接打开 [examples/index.html](examples/index.html)，或在项目目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 [本地示例](http://127.0.0.1:8765/examples/)。主作品是 **连续文本的 3D 粒子线雕转场**：

> 让界面有层次 → 让变化有来处 → 让操作有回音

三句话被组织成相邻的双视角线雕：先由文本 **1 / 2** 的两个视角完成第一次转场，再在文本 **2** 的共同视图上交接文本 **2 / 3**，继续转出第三句。文字本身构成粒子与空间线条；在阅读视图停留，旋转时显露体积。

主作品采用沉浸式深色版面与两行中文粒子字；独立编写的 WebGL 点材质提供高光、有限辉光、空间明暗和指针照明，保留 Canvas 与完整文字替代。排版、阅读正文、分段导航和边缘播放控制一起组成实际 UI。进入页面播放一次，可以随时暂停、反向拖动和跳转到任一句；第二句在两组几何交接时保持同一投影。暂停、隐藏后不会自行重启；减少动态效果保留完整静态文字。16 秒是这个例子的阅读与制作节奏，并非通用时长。

继续向下，三组可操作的 UI 把排版、配色、材质与状态变化放到同一个界面里：

| UI 作品 | 视觉与操作 |
| --- | --- |
| **光谱 / Light Studio** | 深色光学环、连续 alpha 的玻璃表面；切换色光、调整透光，指针改变高光位置 |
| **字场 / Type Composer** | 钴蓝与酸绿、大尺度中文和排版基线；同四个字在大字、留白、错位间续接，调行距、反转配色 |
| **纸间 / Paper Walk** | 朱红背景、纸纹、压印序号和金属箔；选票面、收藏、撤回，状态属于当前票面 |

下方三个操作演示保留原有行为，并使用透明渐变、柔和高光、内容交叉淡入和已确认位置的淡影表达变化：

1. **连续选择**：指示物跟随当前选项，允许快速反向与键盘切换。
2. **保存有回音**：明确标注的本地异步模拟，演示旧结果隔离、同值重发和失败重试。
3. **拖动可以取消**：先预览，合法释放后确认；Escape、目标外释放、失焦会回到已确认位置。

圆环/月牙主题研究仍可展开查看。新 UI 没有持续自动动画，减少动态效果会直接显示目标状态；收藏仅在本页内存中有效，刷新后重置。

演示是为本项目新写的 HTML/CSS/JavaScript，没有外部字体、图片、CDN 或网络请求。它们解释交互取舍，不能替代真实后端、物理触屏或目标应用验收。更多提示词与验收方法见[示例说明](docs/EXAMPLES.md)。

## 验证与打包

```sh
python3 scripts/check.py
python3 -m unittest discover -s tests -v
node tests/text-geometry.cjs
python3 scripts/package.py --output dist/tact-taste.zip
```

纯几何测试需要本机 Node.js；安装技能和浏览器示例运行不依赖 Node.js。

打包仅包含白名单中的文件，输出已存在时拒绝覆盖。静态检查验证结构、相对链接、来源记录和常见私有路径泄漏；它不能发现所有敏感信息，也不证明技能效果或浏览器兼容性。演示的手工验收步骤见[示例说明](docs/EXAMPLES.md)。

## 表达也有自己的标准

创意展示需要一个足够鲜明的主视觉。Tact Taste 把文字尺度、材质、空间层次和转场节奏与可靠控制一起考虑；实现可中断、可访问只是交付的一部分。主示例经过真实作品的视觉比较，具体观察、作者与采用判断见[视觉参考](docs/VISUAL-REFERENCES.md)。

## 从交互大师保留了什么

[保留情况与逐项对照](docs/PRESERVATION.md)列出原技能的核心规则、12 张原始经验卡和 15 条落地经验的去向，以及本轮补回的约束。布局优先、信息克制、构图与终态判断已展开为 [UI 设计指引](references/ui-design.md)；本次新增的实用建议与旧经验分别标注。

这些是有偏好的设计判断，不承诺自动得出唯一正确的界面，也没有用用户研究证明量化收益。三个产品操作演示与视觉作品各有不同的节奏，不应把展示片的排场直接套到日常控件。
