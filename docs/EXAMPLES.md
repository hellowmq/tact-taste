# 示例与验收

## 在真实项目里调用

### UI 层级与视觉状态

```text
用 tact-taste 改善这个设置页的 UI。保留品牌配色、内容和业务入口。
先检查主要任务、分组、留白、对齐、字号关系与控件状态，
优先让布局解释关系；必要的标签和可访问名称保留。
直接落实最有价值的调整，验证窄屏、键盘和保存失败状态。
```

预期交付：说明哪种层级或控件关系得到了改善，提供实际界面证据。不要将“加了阴影/动效”本身当作完成标准。


### 高频切换

```text
用 tact-taste 改善现有筛选栏。保留布局、颜色与筛选业务。
先运行当前页面，指出一个最值得改善的问题，然后直接实现。
验证快速 A→B→C、反向、重复点击当前项，以及键盘操作。
```

预期交付：保留筛选逻辑，同一指示物连续移动；结果与焦点对应最新选择。报告实际运行的入口与未验证项。

### 保存反馈

```text
用 tact-taste 检查设置保存。请沿用现有调度模型，
区分输入值、处理中和已确认值，覆盖慢响应、同值重发、
旧失败晚到和失败重试。不要改变独立业务提交的语义。
```

预期交付：反馈能追溯到对象和操作；重试对应原失败意图。真实后端不可用时，明确说明模拟范围。

### 保留角色动作

```text
用 tact-taste 优化现有桌面角色的选择和拖动控制。
角色外观、动作、播放速度和业务入口已经锁定。
只处理选择反馈、误触、取消与资源清理，并验证实际宿主。
```

预期交付：角色资产与动作保持约定，取消不会触发点击。渲染测试不能代替跨应用物理鼠标或硬件验收。

## 主作品：连续文字，双视角线雕

打开 [examples/index.html](../examples/index.html)，主示例将三个连续文本串接为两段空间转场：

1. **让界面有层次**：正视第一组粒子线雕，留出清楚的阅读阶段。
2. **让变化有来处**：第一组转向侧面，读出第二句；在共同投影中交接下一组几何。
3. **让操作有回音**：第二组继续转向下一视角，读出第三句，并停留。

文本本身由粒子与线条构成。固定字形采样后，第一组几何的两面分别投影为文本 1、2，第二组投影为文本 2、3。第二句保持逐粒子的相同屏幕坐标；交接发生在共同视图，改变的是隐藏的深度坐标。两次转场都通过相机旋转展现，转动中小幅抬升视角以显露空间体积，阅读视图回到正交平面。

主作品使用深色全幅版面与两行中文，把字号尺度、粒子高光、有限辉光、空间线和前后明暗组合成主视觉；播放控制位于边缘，正文说明和三段导航随阅读结构组织。WebGL 负责点精灵材质，Canvas 是无 WebGL 时的替代，两种都不可用时显示完整文字。副文本与控件保持稳定；正文说明跟随已经到达的阅读章节。默认三句同为六个汉字，分成两个三字行，共享“让 / 有”行首和对应基线，保证横向逐行配对有共同的垂直字形范围。这是针对本示例的人工内容编排；任意字体、任意文本或行数不应直接宣称支持。

| 时间段 | 画面与几何 |
| --- | --- |
| 0–2.6 秒 | 文本 1 的阅读停留 |
| 2.6–6.2 秒 | 第一组固定几何，视角从 0° 转到 90°，文本 1 → 2 |
| 6.2–9 秒 | 文本 2 的阅读停留；7.6 秒交接两组几何，共同投影保持 |
| 9–12.6 秒 | 第二组固定几何，视角从 90° 转到 180°，文本 2 → 3 |
| 12.6–16 秒 | 文本 3 的阅读停留 |

上述秒数与角度属于作品选择。可见页面进入后播放一次；用户可以暂停、重播、拖动或反向查看，也可直接选择三句话。系统或手动减少动态效果时不连续播放，直接选择可读的静态文字。指针只影响局部照明，不修改文本、几何或时间。无音轨。

| 操作 | 应看到的结果 |
| --- | --- |
| 播放 → 暂停 → 继续 | 从当前角度续接；暂停停止循环 |
| 从头播放到结束 | 依次读出三句话，包含两次空间旋转和中间阅读停留 |
| 任意 seek、反向经过第二句 | 字形和几何可重建；跨组不闪回、不断开第二句 |
| 选择 1、2、3 句话 | 对应完整阅读视图、正文说明、选中状态和进度 |
| 播放中拖动并在轨道内释放 | 从所选时间恢复拖动前的播放状态 |
| Escape 或轨道外释放 | 回到拖动前的进度；不提交取消的预览 |
| pointercancel、丢失捕获、失焦、隐藏 | 安全取消并暂停，返回后不自动播放 |
| 减少动态效果运行时切换 | 保留当前选择，可直接查看三句静态文字，关闭偏好不自动重播 |
| resize、图形失效与恢复 | 重建当前视图，图形不可用时显示完整文本替代 |

纯几何测试见 `node tests/text-geometry.cjs`：检查两组端点投影、共享第二句、相机方向和反向求值。字形是否可读、文字是否完整、线条密度、阅读节奏、窄屏和控件仍须在浏览器中检查。

## 辅助研究：双视角线雕与主题

展开“更多交互研究”可查看此独立例子。它借鉴本地线雕项目“同一对象切换正交视角”的呈现思路，几何、投影与控制器均为独立新写。人工构造的 28 条空间闭曲线在正面呈圆环，在侧面呈月牙；这是主题演示中的数学构成，不是照片重建、通用线雕求解或实体制造方案。

点击“昼 / 夜”，配色与选中语义立即对应目标主题，线雕视角由临界阻尼响应接向目标角度。反向保留当前位置与速度；同一目标不重复启动动画。主题配色成对切换，避免文字前景和背景交叉渐变时出现低对比度；外围标题、控件和页面内容始终保持稳定。图形在深浅主题中都用本地 Canvas 绘制，不需要 Three.js 或模型文件。

| 操作 | 应看到的结果 |
| --- | --- |
| 昼 → 夜，等待结束 | 同一组曲线转为月牙侧视图，主题状态对应夜间；结束停止绘制 |
| 夜 → 昼，或快速来回切换 | 从当前角度和速度接向新目标，无跳回起点、无多控制器排队 |
| 重复选择当前主题 | 不重播，不重新构造几何，不改动其他示例状态 |
| 用 Tab、Enter/Space 操作主题按钮 | 可见焦点、唯一选中语义与主题一致 |
| 系统或手动减少动态效果，包含运行时切换 | 直接呈现目标主题和目标视角；取消偏好不自行重播 |
| 切后台、失焦、滚出画面、页面挂起 | 完成到已选择主题并停止循环，不留半完成的主题状态 |
| resize、图形上下文丢失/恢复 | 重建当前视角，故障时保留主题状态、可读标题和静态替代 |

这条空间转场判断是本次新示例的设计取舍，不标为原交互大师已验证的规则。应只在这种视觉关系有意义的场景采用。

## 三组视觉 UI

这三组作品默认可见，位于文字线雕下方。它们是独立新写的视觉交互样本，使用系统字体与代码原生的渐变、透明度、变换和 SVG 颗粒；概念图不进入页面。无额外库、素材请求或持续自动动画。

| 作品 | 视觉判断 | 操作与验收 |
| --- | --- | --- |
| 光谱 / Light Studio | 深色、光谱环、透明玻璃与高光边缘 | 三种色光改变同一组表面；透光滑杆连续调整透明层；指针只改变照明。离开、取消或失焦后回到默认光位；减少动态效果关闭指针照明 |
| 字场 / Type Composer | 钴蓝/酸绿对比、大尺度四字构图和基线 | 大字/留白/错位复用同四个节点，快速反向不排队；行距立即影响构图，最大行距不裁切字形；配色反转成对切换，避免中间低对比状态 |
| 纸间 / Paper Walk | 朱红与纸白、纸纹、压印序号、箔片高光 | 票面与可访问名称对应；收藏和撤回直接反映在票面；切换票面清除旧票收藏，不把已收藏状态套给新票 |

纸票是虚构收藏 UI，仅保存在当前页面内存中，刷新重置，不提交订单，不创建后台收藏。玻璃与箔片高光是程序化材质，不是真实光学模拟。上述具体构图和参数是本项目的制作选择，不是适用于所有产品的规则。

## 原操作示例的材质与连续 alpha

原有三个行为示例直接展示，不再藏在“更多交互研究”内。具体状态逻辑保留，视觉层同步更新：

- **连续选择**：同一枚透明渐变指示物续接当前位置；同一组空间表面随选择变化。内容用交叉淡入连接，语义和焦点立即对应新选项；淡出层同时设置 `aria-hidden` 和 `inert`，不再接收操作。重复选择不重播。
- **保存有回音**：输入立即改变阅读预览宽度；输入、处理中和已确认值分开。结果层的高光与边缘表达等待、成功和失败，计时仍只是已标注的本地响应模拟，不能将光效看作真实完成比例。
- **拖动可以取消**：高光滑块负责预览，淡影固定在已确认位置；合法松手后更新确认位置，Escape、目标外释放和失焦取消。回落与高光使用连续过渡，拖动中由指针直接控制。

空间渐变 alpha 与时间透明度分别管理：前者塑造表面、边缘和层次，后者表达状态交接。系统/手动减少动态效果时直接显示当前选择、值和完整文字。验收时检查过渡中间帧、快速反向、键盘与焦点、取消恢复，不能只看终态截图。

## 辅助操作演示

打开 [examples/index.html](../examples/index.html)。可以直接用本地文件打开，也可以按 README 启动本地服务器。所有示例代码为本次独立编写，未拷贝原始 HTML 或外部项目。

页面右上角可主动选择减少动态效果；系统 `prefers-reduced-motion` 也会生效。切换不会丢失选择或当前值。界面使用系统字体，离线运行。

| 演示 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 连续选择 | 快速点击三个选项再反向 | 指示物从当前位置续接，内容始终对应最后选择 |
| 连续选择 | 焦点进入选项后按方向键、Home、End | 焦点、选中语义与内容一致；Tab 可离开选项组 |
| 保存有回音 | 先保存 30，再立即保存 70 | 较晚返回的旧请求不会覆盖新请求的反馈或模拟确认值 |
| 保存有回音 | 同一个值连续保存两次 | 每次生成独立请求代次，最新一次拥有反馈 |
| 保存有回音 | 勾选下次失败，保存；失败后改动输入，再点重试 | 重试提交原失败值，文案明确显示重试目标 |
| 保存有回音 | 让较慢的旧请求失败、较快的新请求成功 | 新成功结果保持稳定，旧失败不显示成当前失败 |
| 拖动可以取消 | 在轨道内拖动并松手 | 预览成为已确认位置 |
| 拖动可以取消 | 拖动中按 Escape 或在轨道外松手 | 回到拖动前的已确认位置，清除拖动状态 |
| 拖动可以取消 | 拖动中切走窗口或隐藏页面，再回来 | 取消预览，下一次操作能正常开始 |
| 拖动可以取消 | 方向键、Home、End | 无需拖动也能调整并确认位置 |
| 减少动态效果 | 系统偏好生效或勾选页面选项 | 取消装饰过渡，选择、完整内容、确认结果继续可用 |

保存使用确定的本地延迟：第一笔 900ms，第二笔 250ms，随后轮换。它是用于复现返回乱序的模拟器；页面中的“模拟确认”不意味着发生了远端写入。取消手势只取消预览。

## 迁移时要改什么

- 将示例的模拟器替换成真实服务，并按照实际业务选择串行、并发或合并策略。
- 将示例的像素、时长和步长视为局部参数，结合宿主和目标用户调整。
- 为真实内容提供必要的名称、状态与恢复文案；不要为了复用示例而增加无关入口。
- 在目标浏览器或原生宿主重新验证；本示例没有证明真实后端、物理触屏、读屏兼容或性能收益。
