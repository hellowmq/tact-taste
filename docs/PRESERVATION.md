## 结论与本轮修正

原有的布局优先、反馈真实性、对象连续性、中断接管、取消恢复、业务约束、键盘、减少动态效果和生命周期原则均有落点。初版确有部分条件被压缩得不够明确，本轮补回：

1. UI 层级、分组、留白、对齐、排版、色彩、构图和控件关系的实际判断。
2. 原生菜单/选择/焦点习惯，以及伴随工具不为展示风格增加常驻面板的边界。
3. 只有合法释放才生成点击、主指针/主按钮归属、移动窗口时坐标系失效风险。
4. 播放前状态的恢复、可访问进度条、快捷键避开输入、全页点击与链接/表单冲突。
5. 暂停静态画面停止空转、按需重绘、CSS 装饰也受暂停控制、恢复时重建时钟映射。
6. 有语义的错峰、长文本总延迟上限、重复视觉语言与稳定结尾。
7. 欠阻尼公式的参数范围，圆角/阴影/滤镜的绘制成本，以及字体/离线依赖风险。
8. 不确定接受结果时的请求措辞、不擅自增加排队、未知值不伪装为零、反馈贴近动作对象。
9. 列表排序取消、多实例重建、画质切换和资源观测，以及跨应用物理鼠标行为的证据边界。

以上为文档语义复核和修正，不等于在所有宿主中证明技能效果。视觉作品及操作示例只支撑本次实际执行的浏览器检查。
