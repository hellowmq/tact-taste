## 采用与扩展

1. 每份新材料记录作者或仓库、原始链接、实际版本、许可证据与采用方式。
2. 区分链接阅读、自行概括、改编代码、原样分发和资产使用；它们需要的许可依据不同。
3. 来源不明的实现或资产先留在公开包之外。单独查到字体或库的许可，不能替整份未知 HTML 授权。
4. 引入第三方代码时，随分发带上其要求的版权、许可和必要说明，并更新本表及文件白名单。
5. 只记录实际执行的核验。网页可读、许可证存在与产品质量验证分别说明。
