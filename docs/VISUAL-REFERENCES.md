## 本版主动选择

- 主视觉由深墨绿舞台、两行中文和银白/青绿/珊瑚色的粒子材质组成。每一句分为两个三字行，字形基线与共用高度带仍参与投影约束。
- 延续文本 1/2 → 2/3 的固定几何；材质、空间线、取景和照明服务于可见的体积。第二句的共同投影继续作为交接点。
- WebGL 着色器用独立编写的圆形点精灵处理高光、有限辉光和轻微倒影；没有 WebGL 时保留 Canvas 绘制路径，两种图形都不可用时保留完整文字。
- 指针移动影响局部照明，不修改文字内容、时间轴或投影几何。进入可见页面播放一次；用户暂停、隐藏或离开后不自动重启；减少动态效果直接阅读完整文字。
- 审美目标是鲜明且可记住的作品。控件和说明保持简洁，不限制主体在材质、构图和运动上的表达强度。

这些是本次设计取舍。真实画面、完整播放和交互检查分别提供证据；不以概念图替代运行结果，不承诺每个人都会觉得惊艳，也不宣称传播或用户研究结果。

## 原材料中的视觉层：2026-10-25 再核对

本轮只读复核持有者本地的四份材料，没有取得新的再分发授权，原文件继续排除于公开包之外。按来源记录的指纹识别，独立概括为：

| 材料 | 本次源码观察 | 迁移方式 |
| --- | --- | --- |
| C-B | 半透明色彩光晕、暗角、颗粒、渐变进度与透明控件 | 材质由背景透光、边缘高光、体积与遮蔽分层组成；不把原来的持续旋转、颗粒循环带入常用控件 |
| M-A | 渐变字面与线条，进入/退出时同时控制透明度和清晰度 | 展示可以让文字和表面具备明暗；新排版 UI 保留完整文字，颜色反转成对切换 |
| C-A | 一个局部进度控制进入/退出的透明包络，同时关联位移、模糊或形变 | 让操作状态拥有视觉层，切换以同一对象续接；时间轴思想不直接充当可中断 UI 控制器 |
| M-B | 同一几何对象的颜色、轮廓和位移连续插值 | 同四个字在版式间变换，空间表面随当前选择变化，不排队播放旧目标 |

光谱、字场、纸间及操作研究均为本项目独立新写的 UI。程序化渐变、透明度和颗粒没有依赖原 HTML、外链字体、图像、音轨或库。U9 将本次的材质和状态判断标为新增建议，避免将新实现冒充原库已有组件或历史验证。
