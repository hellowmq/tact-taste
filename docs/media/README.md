# 展示素材

这些素材用于仓库 README 的简化展示，均来自 Tact Taste 自己的实现，采用项目 MIT。完整示例仍在 `examples/`。

| 文件 | 内容与处理 |
| --- | --- |
| `cover.png` | 实际粒子文字、光谱环、四字排版与纸票的裁切和重新编排；品牌文字与版式由本项目制作 |
| `behavior.png` | 实际选择指示物、保存确认和拖动预览的横向摘录 |
| `behavior-mobile.png` | 同一组操作摘录，改为适合窄屏的纵向排列 |
| `interactions.gif` | 实际 UI 操作录屏的 14 秒片段；缩放至 800px 宽、10fps、160 色调色板压缩，无帧插值 |
| `interactions-poster.png` | 同一录屏片段的静态起始画面，用于减少动态效果或不支持 picture 的阅读器 |
| `showreel-poster.png` | 32 秒 Showreel 的实际编码后首帧；影片画幅与时间轴源码在 `showreel/` |

前五项实现来源：v0.1.0 提交 `5201c2e766fce754b9e8eb5b211eb68b00141919`。Showreel 复用 `b05a92d1b5801f507a37c21ef5e537fb66ded02d` 的示例，加上本项目独立编排的画幅与镜头。图中保存与收藏均为明确标注的本地模拟。

动图默认折叠，展开后观看；有减少动态效果偏好的浏览器选择静态图。GIF 是压缩展示材料，不能用来判断渲染帧率、真机性能或完整交互质量。封面和摘录有裁切，不代表整个页面布局。

文件指纹见 [sources.json](../sources.json)。没有使用参考网站截图、历史未知许可 HTML、概念图或外部素材。原始 QA、浏览器账号信息和机器路径不随素材分发。技能安装不复制这些图片。
